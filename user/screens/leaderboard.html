Leaderboard ​

Audience: Timing operators, organisers and commentators following the results live from inside Manager.

The Leaderboard page is Manager's own live results board: every class in the event, one table each, updating as radio punches arrive, cards are read and statuses change. Nothing needs refreshing. It's the same board the arena TVs show, but laid out for somebody reading it at a desk — and it lives inside Manager rather than on a display of its own.

Opening the Leaderboard ​

Open the event and choose Leaderboard under Event live in the navigation. The Event live group appears once the event has been started, so the page is there in Live and Archive mode but not in Setup.

The page sits inside Manager, so it's protected by the access PIN like every other manager page. It follows your own Manager theme and language rather than a screen's.

Tip: To keep the board up on a second monitor while you work, open the page in its own browser window and drag it across. Every view in Manager is a web page, so a second window stays live alongside the first.

Which classes it shows ​

The page shows every class in the event — you don't choose them. A class added during the event appears on its own. A class with nobody entered in it is left off until somebody is.

Classes are laid out across the columns in a fixed order: by category (Elite, A, AS, Sport, B, N), then by age group, then by name. If even one relay class is on the board, the whole board drops to a single column, because a relay row is too wide to sit beside another class.

Note: To show only some classes, or to lay them out in your own order, use a screen instead and open it in a browser window. Each screen has its own class list; this page doesn't.

What a class table shows ​

Each class is a table headed by the class name. Runners are in the order Manager ranks them: finishers fastest first, then runners on course, then those who didn't finish, with the people Manager knows nothing about yet at the bottom. The full rules are in How results are ordered.

ColumnWhat it shows
Place (unlabelled, on the left)The finishing place, for runners with an OK result. 1, 2 and 3 are coloured gold, silver and bronze once the result is final.
NameThe competitor's name, with their club badge when Show club icon is on. With Competitor time display set to Both, the club name sits on a second line under the name.
ClubThe club, when Club display isn't Hide and the time display isn't Both. Abbreviations shows the first four characters of the club's short name.
StartThe start time, or --:-- when there isn't one. Hidden when Show start time is off.
One column per radio controlThe runner's split at that control. See Radio-control columns.
Penalty and PointsOnly for a score course: the points collected and any penalty for being over time. See Score courses.
FinishThe race time for a finisher, a ticking running time for somebody on course, or the status for anyone else.

The Finish column ​

What's in the Finish cell depends on where the runner is:

  • Finished (OK) — their race time, and underneath it how far behind the leader they are. The time display setting decides which of the two you see. The leader's time is always shown.
  • On course — their running time, counting up every second on a tinted row. It's timed from their start against the event clock, so it is what their race time would be if they finished now. With Show projected times on, a runner who has passed a radio control also shows Predicted: and the finish time Manager expects from their splits so far.
  • On course, but no running time yet — On course shows in place of a time when Manager has no start time to count from, or when their start time hasn't come round yet.
  • Not started yet — the cell is blank until their start time. When it passes, Manager moves them to On course and the clock starts.
  • A status — DNS, DNF, MP, DSQ, OVT, OOC, NT, NP or CAN, shown as a coloured chip. See The status values.
  • No time at all — --:--.

Running times carry on past midnight for a night event, and follow the replay speed during a replay. See Races that cross midnight.

Provisional results ​

A runner who has a radio finish punch but hasn't had their card read yet has a provisional OK. On the Leaderboard the row is tinted and set in italics, and the place gets no medal colour until the card is read. A provisional status, such as an MP from a radio finish, carries a * on its chip. See Provisional vs final OK.

Checked-in runners ​

Reaching the check isn't starting, so a runner who has only checked in isn't shown as on course here. Their row stays as not yet started until their start time passes or a start punch arrives. See Safety check.

Sub-second timing ​

With Use sub-second timing turned on for the event, race times in the Finish column show hundredths (30:00.23). That's the only thing on the board that shows a fraction. Radio splits, behind times, running times and predicted times stay in whole seconds, even though places and split ranks are decided on the fractions. Left off (the default), a whole second is the finest difference the board will separate two runners by. See the setting under Editing event details → Details.

Radio-control columns ​

Each radio control on the class's course gets a column, headed by the control's Radio Name (or its code). For each runner who has passed it, the cell shows:

  • their split time at that control,
  • how far behind the fastest split there they are,
  • their rank at that control, shaded green for the fastest three.

The time display setting decides whether you see the split, the behind time, or both. A blank cell means no punch from that runner at that control yet.

How many radio columns a class gets is set by Max radios (4 unless you change it). When a class has more radio controls than that, the priority you give each one on the Classes page decides which win the space: High first, then Medium, then Low, then those with no priority. Controls set to Hide never show. See Marking radio controls and setting their priority.

Score courses ​

On a score or scatter course, runners choose their own controls in their own order, so nobody runs the same leg as anybody else. A class on such a course shows no radio columns.

A score class adds a Points column just before Finish: the points scored, shown once the result is final. It shows 0 for a finisher who collected nothing, because that is their result. A Penalty column appears beside it only when somebody in the class lost points for being over time. A runner with no penalty shows a blank there.

A class whose competitors do every course in turn, such as a Duo class, has one row per competitor with their overall result. There are no per-course columns yet. A class whose courses are all score courses shows no radio columns. Otherwise the radio columns come from the first course only. See Classes whose competitors do every course.

Relay classes ​

A relay class is drawn as a different table, one row per team:

ColumnWhat it shows
PlaceThe team's place, with medal colours once the result is final.
Team nameThe team, with its club underneath unless Club display is Hide.
TeamThe runners, one per line in leg order, with the club badge beside them. With Show relay team members on single line turned on, they're compressed onto one line.
StartThe team's start time.
Leg 1 …, Leg 2 …Each leg's radio controls, headed with the leg number and the control. A relay shows at most two radio controls per leg, whatever Max radios says, or fewer if Max radios is lower.
Leg 1 finish, Leg 2 finish …The team's time at the end of that leg, from the mass start. Under it is the runner's own leg time, and the team's behind time. If a leg went wrong, the runner's status replaces the leg time, so you can see which runner cost the team its result.
TimeThe team's total time, or the team's status.

Teams are compared only at the radio controls their courses really share, so forked legs still compare fairly. See Relay events for how relay results and leg times are worked out.

Results quarantine ​

A class held back by the results quarantine is shown in full on this page, because it is part of Manager. The arena screens, the spectator app and the kiosk show the quarantine notice in its place until the class is released.

Changing the layout ​

Click the gear icon at the right of the board's header to open the settings. If you've turned the header off, the gear sits by itself above the board instead.

The settings are the same Leaderboard settings an arena screen has — Font size, Columns, Name column width, Club display, Competitor time display, Max places per class, Max radios, Auto-scroll, the header, and the switches for club icons, relay team members, projected times, start times and class names. What each one does is in the settings table on Creating screens. Apply saves and keeps the dialog open; Save saves and closes.

Some settings are left out because they belong to a display device: Shows, Theme, Language, the Snapshot tab and Delete. This page always shows the Leaderboard, in your own theme and language.

A few of the starting values differ from an arena screen's, because one person reads this board up close rather than a crowd from across the arena:

SettingStarts at on this page
Auto-scrollOff — a board that moves while you're reading it is no help at a desk
Club displayHide, to give the width to the results
Show class names in headerOff — the board carries every class, so the header shows the event name instead

All of them are yours to change. The settings are kept with the event and apply to whoever opens this page for that event. They are stored as the event's manager screen, which is also listed on the Screens page and can be configured from its gear icon there. Changing them never affects an arena TV, including the all screen.

Max places per class ​

Max places per class set to a number (top 3 to top 10) shows only that many finishers per class and hides everyone else, including runners still on course. A line under the table says how many are in the class: Current top 3 (12 total) while the places can still change, and Top 3 (12 total) once they're settled.

The header ​

With the header on, the top of the board shows the meshO logo, the event name, the event clock and the gear. It stays at the top as you scroll. Turning Show class names in header on puts every class name there instead of the event name.
