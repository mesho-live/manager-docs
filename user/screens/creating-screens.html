Creating screens ​

Audience: Event organisers and operators setting up spectator-facing displays.

A screen is a display you configure once and then open as a web page on a TV, laptop or tablet. Each screen has its own ID, its own layout, and — the first thing you choose — its own content: what it actually shows. Because a screen is just a web page, nothing is installed on the display device: you point its browser at the screen's URL and leave it running. See How meshO Manager works for the one-server, many-browsers model.

A screen can show:

  • Leaderboard — live results, class by class. This is what every screen shows unless you change it.
  • Start times — the start list, grouped under class or course headings.
  • Live top 10 — a wall of live top-10 boards, one per class. The same graph the spectator and kiosk screens draw, on a TV.
  • Time behind Superman — a wall of Time behind Superman graphs, one per class, ten runners each. The finisher graph: it draws the races that are already in, so it is the screen for the half-hour after a class comes home.
  • Position bump — the same wall drawing each runner's place overall after every leg, so you can see who was gaining and who was slipping back.

So a hall with ten TVs might run the Leaderboard on seven of them, start times by the start lane, a Live top 10 wall over the finish, a Time behind Superman wall by the download desk, and a different set of classes on each of the rest. You choose per screen, in Manager — a TV has no controls on it and nobody needs to touch the display itself.

These are the arena displays you build here. They're separate from the built-in Spectator and Kiosk views — the public, self-serve pages competitors open on their own phones — which need no setup. See the glossary for the distinction.

The Screens page ​

Open Screens from the event navigation. It has three sections:

  • Screens — every screen in the event, one row each, with what it shows and how it's doing.
  • Commentary — open the announcer's live feed. See Commentary.
  • Video — the arena cameras and their recordings.

Every event has two built-in screens. all shows every class and is the simplest thing to put on a single display. manager is the Leaderboard page inside Manager itself — it's listed here so you can set its layout, but it has no display device behind it, so its Last heard from cell stays blank and it has no reload button.

For a bank of TVs set up and managed together, see TV screens.

Creating a screen ​

Click New, give it a Screen ID, choose what it Shows and its Theme, and click Create. The ID is how you refer to the screen and it appears in the screen's URL, so keep it short and memorable (elite, juniors, arena1). It must be unique within the event.

Shows and Theme are asked here, rather than left to the gear icon afterwards, so a screen created for the start lane isn't a Leaderboard for however long it takes you to open its settings. Both default to what most screens are: Leaderboard, and Light.

A new screen inherits your global screen defaults (set on the Settings page) for club display, club icons, auto-scroll, the header, max radios, time display, single-line relay members and max places. Font size and columns are not among them — every new screen starts at 10 and 2 — and you can fine-tune any of it afterwards. A new Leaderboard starts with no classes, so the next step is to choose them.

There's another way to make a screen, and it's often quicker: just point a browser at a screen URL that doesn't exist yet. A TV opened at /screen/tv9 creates tv9 and it appears on this page ready to be told what to show. A screen made that way starts at font size 14 rather than 10.

Choosing what a screen shows ​

Click the gear icon in a screen's row and set Shows to either Leaderboard or Start times. The rest of the settings follow that choice, so you only ever see the ones that apply.

A Leaderboard screen: which classes ​

There are two places to do this, and they do the same thing.

In the screen's row, the Classes column:

  • Click the expand arrow to see the classes currently on the screen as chips.
  • Click the + (add) button to open the Add classes dialog — search by class name (the table also shows which other screens already show each class), tick the ones you want, and Add.
  • Remove a class by clicking the × on its chip.
  • You can drag class chips between screens in the table to move them around quickly.

In the screen's settings, under Classes: the classes laid out the way the screen will lay them out — the same number of columns, filled in the same order. Drag one into a cell to move it there, × to remove, Add classes beside the heading to add more. Changes here are saved with Apply or Save like everything else in the dialog, so you can back out with Cancel — unlike the table row, where removing a chip takes effect straight away.

On a Leaderboard the grid follows the Columns setting, so changing it re-shapes the preview and you can see where each class will land. It shows which column a class is in and where in it; it can't show height, because a real column is as tall as the fields in it.

The all screen is special — it always shows All classes and you don't manage its class list. Nor does manager, which shows every class too.

A Live top 10 screen: which classes ​

Assign classes exactly as you would to a Leaderboard — either the Classes column in the screen's row, or the Classes section in the screen's settings.

In the settings, the class grid works as it does for a Leaderboard, except that a wall chooses its own shape rather than following a Columns setting — so it re-shapes as you add and remove, because the wall does. A wall's grid is exact: each cell is one board.

A wall holds 12 classes, and the settings will not let you go past it: Add classes stops offering once you are at twelve, and the picker says how many the screen takes. Remove one to make room.

A screen can still end up with more than twelve — assigned from the table row, which has no limit, or set up by an older version. The television draws the first twelve in your order and the screen's row says First 12 only; the extras stay on the screen and are managed from that row.

Each board is the same Live top 10 graph a spectator sees: one lane per runner, ten deep, including everyone still out in the forest. It sizes itself — how much each board says shrinks as you add classes — so there is no font size or column setting on this screen, and nothing scrolls. What you get is what fits.

A class the graph cannot draw — a relay, a score course, one with no course — says so on its own tile rather than being left out, so you can see that you assigned it.

The wall's header names the graph, Live top 10, rather than the event: somebody crossing the arena is looking for where the live standings are, and every tile already names its own class.

Live position — the other graph on the spectator wall — is deliberately not offered here. It refuses a class with no radio control rather than falling back to the controls on the course, so on a hall where not every class is wired you would get a wall of refusals. Live top 10 keeps reading either way.

An analysis wall — Time behind Superman or Position bump: which classes ​

These two are the same screen drawing two different things, so everything below applies to both. Assign classes the same way again — the Classes column in the screen's row, or the Classes section in the screen's settings — and the grid in the settings re-shapes as you add and remove, because the wall does.

Either wall holds 4 classes, laid out two across and two down. That is fewer than a Live top 10 wall on purpose: a live board can give up what it says — the club, the leg times — and still show you the runners, while this one is a plot with ten lines on it and a name beside each, and there is nothing on it to give up. Four is what stays readable on a TV. Add classes stops offering once you are at four; remove one to make room. A screen given more than four (from the table row, which has no limit, or by an older version) draws the first four in your order and its row says First 4 only.

Each tile draws the top ten of its class.

On Time behind Superman, Superman is a runner who never existed: someone who took the fastest split on every leg of the course. Their total is what the race could have been won in if all the best splits had belonged to one person. Every line shows how far behind that a runner stands at each control, so a line that drops steeply is time lost on that leg — usually a mistake — and a line that stays flat is a leg run at the best pace in the field. Underneath, the ten are listed in finishing order with the gap each finished on. The perfect race is built from the whole class, not just the ten drawn: a runner well down the results who was fastest on one leg still counts, which is what makes the figure "how fast this course could have been run".

On Position bump, each line is a runner's place overall after every leg — 1 is whoever led the class at that point. A line climbing toward the top is gaining places and one falling away is slipping back, which is the race as it would have unfolded live. It starts at the first control rather than the start line, because nobody has a place at the gun, and the legend lists the ten with their race times. Places are counted across the whole class, not across the ten lines drawn, so a tile for a class of forty shows real positions rather than 1 to 10.

Both are finisher graphs — they are drawn from downloaded cards, so a class where nobody has come in yet says so rather than sitting blank, and fills in as the cards are read. A class neither can draw at all — a relay, a score course, a class running several courses — says that on its own tile instead, so you can see that you assigned it.

Like the Live top 10 wall they size themselves, so there is no font size, columns or auto-scroll setting, and nothing scrolls. The header names the graph rather than the event.

Letting the wall choose: Cycle through all classes ​

Tick Cycle through all classes in the screen's settings and the wall stops reading its class list and works through the whole event by itself. It shows the first four classes, then the top two slide off the top, the bottom two slide up to take their place and the next two come in from underneath. At the end it wraps round to the first four and keeps going.

Seconds — beside that tick box — sets how long each screenful is held: ten by default, and anything from five seconds to two minutes. A TV by the download desk that people walk past wants longer than one over the finish that everybody is already watching. The slide itself always takes two seconds on top of that, and is deliberately slow: it has to be possible to follow your class from the bottom half of the screen to the top.

Classes come in the event's own class order — the one you set in Classes → Sort order — and only the ones these graphs can draw are included, so relays, score courses and classes running several courses are passed over rather than given a turn on the wall to say they can't be drawn. A class nobody has downloaded from yet is included; it fills in as the cards are read.

With the setting on, the Classes section disappears from the settings, because there is nothing left to arrange, and the screen's row in the Screens table says All classes instead of counting them. Your chosen classes are not thrown away — untick the box and they are back exactly as you left them. If the event has four classes or fewer, the wall shows them all and simply sits still; there is nowhere to cycle to.

A Start times screen: by class or by course ​

In the screen's settings, choose Group by — Class or Course — and then tick the classes (or courses) to show. One button at the top of that list toggles between Select all and Deselect all, depending on what's ticked.

With everything ticked, the screen stores "all" rather than today's list, so a class entered at nine in the morning turns up on the TV by itself. That matters because nobody is standing at the screen to re-pick it. If you tick only some, the screen shows exactly those and nothing else.

Because "nothing ticked" is how the screen stores "everything", it can't also mean "show nothing" — a screen showing nothing isn't a useful thing to configure. So if you clear the list, Save and Apply are disabled until you pick something, or select all again.

Your two lists are kept separately: switch a screen from Class to Course and back, and the classes you picked are still there.

Two more switches sit under that picker:

  • Only classes with start times (or Only courses…, following the Group by choice) leaves off a class nobody is starting in. Off by default, because before the draw is done that would empty the board — an empty board looks broken. Turn it on the morning of the race, when a class nobody is starting in is a column of nothing taking room from the ones that are. It works per class, not per person: a class where one runner has no time yet still shows, with that runner in it.
  • Show club names each competitor's club beside them. On by default.

A few things worth knowing about a start times screen:

  • It shows the time each competitor is due to start, not the time they actually went. Somebody who has taken a punching start still appears at their allocated time.
  • Competitors marked Did not start, Not participating or Cancelled are left off. Anyone with no start time yet is still listed, at the end of their group.
  • Relay teams appear as teams, once each — not as their individual leg runners.
  • Grouped by Course, each row also names the competitor's class, because one course heading covers several classes. Grouped by Class, the heading above already said it.
  • Times show seconds only when some start isn't on a whole minute — and then on every row, so the column doesn't step sideways as the board redraws.
  • If anyone's class or course can't be worked out, they get their own No class / No course group at the end rather than being dropped. Somebody left off a start list would read it as not running. (This only happens when you haven't narrowed the screen to particular classes — a screen asked for M21 isn't also asking for the undecided.)
  • Before anything is entered, the screen says so and points you back here.

It doesn't need the event to be started, so you can prop one up first thing in the morning and it will already be showing the day's start list.

Adjusting a screen's settings ​

Click the gear icon in a screen's row to open its settings. There are two tabs.

Settings — the layout and content of the display. Shows, Theme, Language and Show Header apply to any screen. Font Size, Columns and Auto-scroll apply to a Leaderboard and a Start times screen — the walls decide all three for themselves. The start-times settings appear only on a Start times screen, and everything else in the table below only on a Leaderboard.

Changing what a screen shows can leave it carrying more classes than the new display can draw — a Leaderboard with ten classes switched to an analysis wall, which holds four. The surplus come off the screen as soon as you choose, keeping the order you arranged them in, so the class grid redraws as the four that will actually be on the TV. Cancel puts them all back if that wasn't what you meant. Switching the other way — to a display that holds more — brings back any classes the screen was carrying but not drawing.

Theme is Light or Dark, and it is the screen's own — set it per screen, or set every Leaderboard TV at once with Edit all Leaderboards (that button only appears once the event has at least one tv-named Leaderboard screen). New screens are light. There is deliberately no "follow the device" option: a TV has nobody standing at it, and a board that went dark because the stick driving it decided it was evening would have changed without anyone asking.

Snapshot — click Refresh Snapshot to capture a live screenshot of the screen as it currently renders. It's the quickest way to check the layout looks right without walking over to the TV. (A snapshot only works while the screen is open somewhere.)

Use Apply to save and keep tweaking, or Save to save and close.

Keeping an eye on a running screen ​

Once a screen is open on a display, its row reports live health so you can spot a TV that's dropped off:

  • Last Heard From — when the screen last checked in. Green means it's reporting now; grey means it's gone quiet.
  • FPS — how smoothly it's refreshing (green is healthy, orange is marginal, red is struggling). Click the number for a history graph that also marks disconnects, reconnects and reloads.
  • DC / RL — counts of disconnections and force reloads, flagged when they happen.

Deleting a screen ​

Open the screen's settings (gear icon) and click Delete, then confirm. The built-in all screen can't be removed.
