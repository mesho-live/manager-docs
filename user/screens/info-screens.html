Event info screens ​

Audience: Organisers and timing operators putting view-only screens up around the arena, and the start-lane or download-tent volunteers who read them.

The info screens are four full-screen displays you prop up where people need to see something: a clock at the start lanes, upcoming starters box by box, who has just come past a radio control, and who still has to download their card. You open one on a tablet, a laptop driving a TV, or a phone, choose what it shows, and walk away.

They are deliberately narrow:

  • Nothing on them changes the event. They only read. There is no editing, no card download, no way to alter a result from one.
  • Nobody has to stand at them. The device stays awake on its own and the screen keeps working unattended for the rest of the day.
  • They follow whichever event is live. There is no event picker, so the same link works at your next event. A screen switched on before the event starts waits and picks the event up on its own.

Opening a screen ​

Each device opens the same address — the server address followed by /info:

http://<server-address>/info

The easiest way to get it is Settings → Server → Access links, where it is listed as Event info screens. Copy that link to the device. Which of the two links to use — the name one or the IP one — depends on the device; see Reaching the server: name or IP. Phones, tablets and TVs normally work with the name link.

Then, on the device:

  1. Open the link. The menu above appears.
  2. Tap the tile for what this screen is going to show. That tap also takes the browser's address bar off, so the screen fills the display.
  3. Prop the device up and leave it.

Tip: The link carries no event id, so it does not go stale. A tablet set up at the start lane this weekend will pick up your next event without anyone touching it.

Note: Taking the address bar off only works if you tap a tile — a browser will not let a page go full-screen on its own, so it can never happen on a reload. If a screen restarts and comes back with browser chrome around it, open its settings (below) and press Close to get full-screen back. Some devices refuse full-screen altogether (an iPhone has no way to do it at all); the screen still works, it just keeps its address bar.

Changing settings, and getting back out ​

Every screen has a small cog in the bottom-right corner. Press and hold it for two seconds — a ring fills round it — and the settings sheet opens. A hint saying so appears for the first few seconds after a screen opens, then fades.

The sheet holds that screen's own settings, plus two buttons:

  • Close returns to the screen and re-takes full-screen.
  • Back to the menu leaves the screen and hands the browser back, so you can pick a different one.

The two-second hold is the only way off a screen: a stray tap, a swipe, or the browser's Back button will not do it. That is on purpose — these screens stand where the public can reach them.

Warning: The hold stops an accident, not a person. Anyone who works out the gesture can leave the screen. If you need a display that genuinely cannot be got out of, lock the device itself — Android's screen pinning, or Guided Access on an iPad.

Settings are remembered per device ​

Each screen's settings are stored in that device's browser, not in the event. A tablet that reloads — or whose battery dies and is plugged back in — comes back showing the same thing it was showing before, without anyone walking over with a laptop. It also means two tablets can show different things, and that setting one up does not change the other.

Warning: If the sheet shows This device cannot save settings, that browser is refusing to store them (a private-browsing window, or a locked-down kiosk profile). Your choices hold until the page reloads and are then lost — and the defaults are not neutral: a silent pre-start clock comes back as an event-time clock with the beeps on, which sounds a start signal several minutes early. Use a normal browser window on that device, or check the screen after every restart.

Start clock ​

A full-screen clock, sized to be read across a start field. The digits change exactly on the second, because someone is going to step over the line as they do.

This clock shows picks between two things:

  • Event time — the actual time. This is the clock at the line.
  • Pre-start −1 … −5 — the clock for a call-up box. It shows the time the runners standing in front of it will start, with a large −3 badge naming the box and the real event time kept small in the top-left. A start official reading a −3 clock still needs to know what time it actually is, and a runner who reads a −2 clock as a −4 one walks into the wrong box — hence the size of the badge.

Note: A pre-start clock shows hours and minutes only, and rounds up to the start the box is waiting for. It is not telling you the time — it is showing the number printed on the start list of the runners in front of it, and that is always a whole minute. It changes on the move-up, so everyone standing in the box through that minute reads the same start time.

Appearance is Dark or Light — pick it for where the screen physically stands (bright sun, a dim tent), not for what the device's own theme is set to.

Beeps ​

Pre-start −NTwo very short blips on the interval, to move the boxes up.Off

The pattern follows the mode — it is not a separate setting. A pre-start clock deliberately does not count down, because nobody starts at it and a lead-in there is a false start signal every couple of minutes all morning. The double blip matters for the same reason: a single beep beside a start lane is the sound everyone within earshot is listening for, so a box that is only shuffling forward must not make one.

Beep interval offers every 30 seconds, every minute, every 2 minutes, or every 3 minutes. Two minutes is the default.

Short beeps is how long the countdown is on the clock at the line: 2, 3 or 4 short beeps, one per second, ending on the long one. Four is the default — a runner who hears the first of four has a whole second to look up before the three that mean now — and two is there for a lane running 30-second intervals, or one standing within earshot of another, where four is simply noise.

Warning beep 10 seconds before adds one beep ten seconds ahead of each start, for a lane with a long call-up. It is off unless you ask for it, and it is deliberately a lower, slower sound than the countdown beeps: nobody should be able to hear it as the countdown having started and step off early.

Note: Both of those settings are only offered when the clock is showing Event time. A pre-start clock is not counting down to anything, so there is no lead-in to lengthen and no start to warn of. Your choices are remembered while it is set that way, and come back if you set it to event time again.

Warning: Check the beeps before the first start. A browser will not make a sound until the page has been touched, so a clock that has just reloaded shows Tap the screen once to let this device play the beep across the bottom — and until somebody does, it keeps perfect time in silence. If it instead says the device cannot play the beep at all, that device has no usable sound output; the clock still runs.

Starters ​

Upcoming starters, one column per pre-start box. Two people read it: a competitor checking whether they are up next, and the start team checking the right people are standing in the right box.

A column is a clock time, not a place in the start list. The −4 column is whoever starts four boxes from now, whether that is six people or nobody. An empty box is worth showing: it tells a start official the lane is about to have a gap, and it says so under the heading Nobody.

The columns count down to the line — the box furthest from starting on the left, the runners about to go on the right — so the screen reads the way the lane is walked.

Set Start interval to the interval your start list was drawn on: 30 seconds, 1 minute, 2 minutes or 3 minutes. It is what the columns are counted in, which is why the sheet asks for it first. On a 30-second start the headings carry seconds as well, since two boxes half a minute apart cannot be told apart by the minute alone.

In Columns you then tick which boxes this screen draws:

  • Next is the next start time anyone is actually in, however far ahead that is. Where the lane is running to time it is the same as the first box; where the start list has a gap in it, it is the more useful answer.
  • The other seven are the boxes behind it, and each is labelled with how far ahead of the line it is rather than with a number to multiply — so a 30-second start offers −30 sec, −1 min, −1m30s, −2 min, −2m30s, −3 min, −3m30s, and a three-minute start offers −3 min through to −21 min. Change the interval and the labels follow it.

Each card shows the competitor's name with their class and course beneath. Anyone marked as not starting — did-not-start, not participating, cancelled — is left out, as is anyone who has no start time yet. A box holding more names than fit scrolls on its own, without moving the columns beside it.

Size (Small, Medium, Large, Huge) sets how big the cards are drawn. Pick it for the reading distance: Huge for a screen people walk past, Small when you want as much of the lane on screen as possible.

Radio control ​

Who has just come past a radio control, newest first. This is the screen for a spectator control or a changeover — the one people stand and watch.

Every time it opens it asks which controls to watch:

The list holds every control you have flagged as a radio, plus any control code that is actually reporting punches even if nobody flagged it. The Punches count is how you tell a control is alive before you commit a screen to it. Tap as many tiles as you want — they stay lit — then Watch these controls.

The screen asks every time because a tablet is usually carried to a different control at the next event, and a feed that quietly came back on yesterday's control would show the crowd the wrong names. Whatever the device was watching last is already ticked, so carrying on where you left off is one tap.

Each card reads left to right:

  • PLACE — where they are in the race right now. In a relay this is the team's place, because that is the standing anyone at the fence is following, not the leg runner's rank among every runner in the class.
  • Name, with class and course beneath.
  • AT THE RADIO — the time of day they came past.
  • PREDICTED FINISH — the time they are on course for, while they are still out.
  • TIME and a status chip — once they finish, the row swaps the prediction for the time and status they ended up with. Somebody who came past twenty minutes ago has usually finished by the time anyone reads the bottom of the screen.

Note: A time in italics with a trailing asterisk came from the radio finish and has not been confirmed by a card download yet. It is a real time, but it can still change. See Downloading cards.

Columns lays the feed out 1 to 4 across. One column suits a tablet held upright beside the control; three or four put much more of the field on a big TV at once.

Watching more than one control ​

An arena often has more than one radio worth showing — the spectator control and the run-in, or two changeovers — and rarely a second tablet for the second one. Pick more than one on the picker — or add them later under Controls in settings — and the screen splits into a column per control, headed by that control's name, drawn large enough to read from where the crowd is standing. The heading is what tells anyone which control the names under it came past, so it is not something to squint at.

Each column holds its own feed, newest first, and scrolls on its own without moving the columns beside it. The count under a heading is that control's punch total — the same "is it alive" check the picker gives you, kept on screen all day.

Columns greys out while more than one control is ticked: the controls are the columns then, and three across inside each of them is not a layout anyone wants. Untick back down to one control and the setting comes back. Untick them all and the screen returns to the picker.

Pending downloads ​

Who the finish saw come home but whose card has never been read — the runners who walk off to their car with the card still in their hand.

Put this one where finishers can see it: outside the download tent, or at the exit of the arena. Longest overdue is at the top, and the count beside the title is the number outstanding. When the last card is read the screen says Everyone has downloaded.

Competitors still out on the course are deliberately not on this list. They are a different problem — somebody who may still be running, or may be hurt — and putting them here would bury the two or three names the download tent is chasing under the whole field for most of the morning. For who is still in the forest, use Safety check: accounting for everyone.

Note: This screen needs a radio finish control. Without one, nothing distinguishes a runner still in the forest from one who has gone home, so the screen has nothing to show. See Radio punches.

When the network drops ​

These screens are built to survive an outage that lasts the rest of the event, and they mostly do — but it is worth knowing what you are looking at.

  • Lists do not blank. Whatever a screen had read stays on it. The starters screen keeps filling and emptying its boxes correctly for as long as the tablet has power, because its columns are minutes counted off the clock against start times that were settled before the race began.
  • The clock keeps time. It carries on from the last reading it got from the server.
  • A warning appears beside the clock once the link has been down for a while, and clears the moment it comes back. The start clock deliberately never shows it: it is read by everyone walking up to the line, and a warning symbol there would tell a hundred competitors their start times are in doubt in order to tell one official something they can read off any other screen.
  • A screen that could not read the event at all says Could not read the event. What is shown may be out of date. rather than showing an empty list — because "everyone has downloaded" and "we never got the list" look identical otherwise.

Warning: Do not reload a screen during an outage. The page itself comes from the server, so a reload lands on an error page and the screen cannot come back until the network does. Leave it alone; it recovers on its own when the link returns.

If a screen shows There is no live event at the moment, no event has been started yet. Leave it up — it starts on its own as soon as one is under way. And if it complains that the device's time zone does not match the event's, fix the time zone in the device's own settings: everything on these screens is a clock time, and it will be wrong until you do.

Practical setup ​

  • Plug the device in. The screens hold the display awake, which is what you want and also what flattens a battery by lunchtime.
  • Check each screen once it is in place, from where people will actually read it. Size is the setting operators most often get wrong from a metre away.
  • Anyone on your network with the link can open these screens. There is nothing secret on them — they show what the spectator screens show — but do not treat the link as private.
