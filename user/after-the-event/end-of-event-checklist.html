End-of-event checklist ​

Audience: Event organisers wrapping up after the competition.

A printable checklist of what to do once the last competitor has finished or been accounted for. Each item links to the page that explains it.

Before anyone leaves the venue ​

Everyone accounted for

  • [ ] The dashboard's On course count is zero, or everyone still on it is known about. See Safety check: accounting for everyone.
  • [ ] Read the Start, Check and Finish stations' memories if anyone is unaccounted for: a runner who punched the finish but never downloaded shows up there. See Reading SportIdent stations.
  • [ ] The Pending count is zero: every radio finish has had its card downloaded. See Who is still on course.

Every result settled

  • [ ] Sort out disputed results and missing punches on the competitor. See When a result is disputed and Resolving issues on the day.
  • [ ] Mark the non-starters DNS: Competitors → Actions → Set competitors DNS… does a whole class at once.
  • [ ] Anyone still out who has been seen on course: Overtime or DNF.

Finish

  • [ ] Click Finish event. If anyone is still unsettled, Event not finalised lists them with the buttons that settle them. It won't finish past a radio finish whose card hasn't been read. See Settling everyone first.

Hire items

  • [ ] Collect every hire card and lent item: filter the Hire items screen to Out to see who still has one. See Hire items.

Publish

  • [ ] Upload the results to Eventor: Results → Publish → Upload to Eventor. See Uploading to Eventor.
  • [ ] Export any files your federation or another system needs. See Exporting data.
  • [ ] Print or pin up the results, and the prize-giving list. See Prize-giving and the results board.

Keep a copy

  • [ ] Take a backup: Backup event → Download on the event's card, and keep it somewhere other than the server computer. See Backup and restore.
  • [ ] Take the external backup drive with you.

Note: Finishing the event isn't final. If a competitor turns up afterwards, even the next day, open the event and click Restart event to take it live again, download their card, and finish it again. Upload the results again afterwards. See Restarting an event you've already finished.

Back at home ​

  • [ ] Upload or export the results if you couldn't at the venue, and upload again after any correction.
  • [ ] If cloud sync is on, check the event has published. Its card on the Events list shows a cloud with a tick once it's on the cloud. See Settings.
  • [ ] For a series or a carnival, carry today's new cards and class changes into the next event with the changes report.
  • [ ] Return borrowed hire cards to their owners, using each card's Owner in Settings → Hire card registry.
  • [ ] Note anything that went wrong on the day, and what fixed it, for next time. The audit trail shows what was changed and when.
  • [ ] Shut the server computer down if it isn't a permanent installation: Quit from the tray or menu bar first.
