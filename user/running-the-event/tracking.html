Tracking ​

Audience: Timing operators looking after the meshO Athlete units (GPS trackers) competitors carry.

How to use the Tracking screen to keep an eye on the trackers: which are reporting, which have gone quiet, which are running low, and which are sending to Livelox.

What it's for ​

Tracking is a table of the meshO Athlete units heard by meshO Prime: one row per unit. It's about the trackers themselves, not results. To see where they are on a map, use Live view. For split times and positions, use the leaderboard screens and Commentary.

Open the event and choose Tracking under Event live. It's there while the event is running, and only for an event that uses meshO Prime (Event details → Radio Controls → meshO Prime). A unit appears once Prime has heard from it.

The table ​

ColumnWhat it shows
IDThe unit's serial number.
StatusHow recently the unit reported, and whether it has a position (below).
BatteryThe battery level. Click it for the unit's battery history.
Last locationWhere it last reported being. Click it to see the unit's track on a map.
Last seenWhen Prime last heard from it, and how long ago.
LiveloxWhether the unit's track is sent to Livelox, and how many positions have been sent and are still waiting.
ActionsDownload GPX track, Clear all locations and Delete athlete and all data.

Status ​

StatusMeaning
GoodHeard in the last 30 seconds, with a position from the last 2 minutes.
AcquiringHeard recently, but without a recent position: usually a unit still finding its GPS fix, just switched on or under cover.
OKHeard in the last 2 minutes, with a recent position.
WarningNot heard for 2 to 5 minutes.
StaleNot heard for more than 5 minutes.

A Warning or Stale unit is out of radio range, switched off, flat, or carried somewhere the network doesn't reach. Its last location is where to start looking.

Before the start ​

  1. Switch on every unit you're handing out, with Prime connected and the event running.
  2. Check each one appears in the table and reaches Good. Acquiring for more than a few minutes usually means the unit can't see the sky.
  3. Check the batteries: replace or charge any that are low now, rather than have them go flat on course.

During the event ​

  • Units going quiet: watch for Warning and Stale. Click Last location to see the unit's track up to the moment it went quiet.
  • Low batteries: the battery history shows how fast each one is falling.

Livelox ​

Switch Livelox on for a unit to send its positions to Livelox, about every five seconds while it has new ones. Manager identifies the unit to Livelox by its serial number (the ID column), so whoever is carrying it has to be set up against that number on the Livelox side. With Livelox on, the column shows how many positions have been sent and how many are still pending. Pending ones go when the connection allows.

Tidying up ​

  • Download GPX track saves the unit's route as a GPX file for mapping or route-analysis software.
  • Clear all locations removes the positions recorded for the unit, for example after a test run before the event. It asks first.
  • Delete athlete and all data removes the unit and everything recorded for it. It can't be undone.
