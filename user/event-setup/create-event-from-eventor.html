Creating an event from Eventor ​

Audience: Event organisers whose federation uses Eventor for entries.

How to create a new event by importing it directly from Eventor — classes, competitors, clubs, and start times in one step; just import course files.

When to use this ​

Use New from Eventor when:

  • Your federation publishes the event on Eventor and accepts entries there.
  • You've configured the Eventor connection in Settings → Eventor.
  • You want classes, competitors, clubs, and (if available) start times pulled in automatically.

If your event isn't on Eventor — or you only have IOF XML files — use New Event instead and import data afterwards from files.

Prerequisites ​

Before the New from Eventor button will work, configure the connection once in Settings → Eventor:

  • Host Name — the URL of your Eventor instance (e.g. https://eventor.orienteering.org.au).
  • API Key — your Eventor API credentials.
  • Organisation ID — your club or federation's Eventor organisation ID.

If Eventor isn't configured, Manager will tell you when you click New from Eventor and point you to Settings.

Creating the event ​

  1. On the Events page, click New from Eventor.
  2. Manager fetches a list of upcoming events from your organisation. Use the search field to narrow it down by name.
  3. Select the event you want to import.
  4. Manager runs through the import in steps and shows progress for each:
    • Fetching event details
    • Fetching classes
    • Fetching entries
    • Fetching start times
    • Importing data
  5. When the import finishes you'll see a summary:
    • Classes imported
    • Competitors imported
    • Clubs imported
    • Start times allocated — or "not yet available" if the draw hasn't been done on Eventor yet
  6. Click Open Event to go to the new event's dashboard.

The event is created in Setup mode with defaults inherited from Settings → Event Defaults — same as any other new event. Only the name, date, discipline, classes, competitors, clubs, and start times come from Eventor.

The discipline comes from the race distance the organiser set on the Eventor event, and covers both the course lengths (Sprint, Middle, Long, Ultra Long) and the competition formats Eventor lists beside them (Knock Out Sprint, Sprint Relay, Mass Start, Pursuit, Relay, Mixed Relay, Qualification, PreO, TempO). Eventor treats Middle as its default, so an event that doesn't set a distance imports as Middle — change it in the event details if it's wrong.

The discipline is a description of the race. It doesn't make the event a relay on its own — that's the event type, chosen during the import.

After import ​

The event is linked to its Eventor source. That link gives you two things:

  • Re-import later — as entries close and the start list draw is published, you can pull the latest data without searching for the event again. See Re-importing from Eventor.
  • Publish back to it — the linked event is pre-selected when you upload the start list or, after the event, the results.
  • Traceability — the link is recorded on the event so you can see where the data came from.

You'll typically want to:

  1. Open the event details (edit icon on the Event header card on the dashboard) and review the name, date, and radio unit numbers. See Editing event details.
  2. Import courses separately — Eventor doesn't carry course definitions. Upload an IOF CourseData XML or Purple Pen file via the Data Imports section or the Import Data dialog. See Importing course data.
  3. Check the imported data:
    • Open the Classes page — confirm the right classes exist (course assignment comes after importing courses).
    • Open the Competitors page — confirm card numbers and class assignments. Sort by card number to spot blanks.
    • If start times were imported, the Competitors page shows each competitor's allocated time and its source.

Importing into an existing event instead ​

If you've already created an event with New Event and want to pull Eventor data into it after the fact — use the Import Data dialog from the dashboard. See Importing into an existing event.
