Pre-event checklist ​

Audience: Event organisers making sure everything is ready before event day.

A printable checklist of what to do in the weeks, days and hours before a competition. Each item links to the page that explains it. Skip what your event doesn't use: a club event with no radios has no meshO Prime to test.

Weeks before ​

The event

  • [ ] Create the event, from Eventor or by hand, and check its date, type and discipline. The type can't be changed afterwards. See Creating an event and Creating an event from Eventor.

  • [ ] For a carnival or a knock-out, create the multi-stage event or knock-out competition and its days.

  • [ ] Go through the Event details tabs once (the Event details button at the top of the dashboard). On Details: the Timing card system (SportIdent or EMIT — it locks when the event starts), the Time zone, a Course closure time if you want one, and Use sub-second timing only if the race is genuinely timed to fractions. See Editing event details.

  • [ ] For a club training or come-and-try day with no entries beforehand, see Low-key events: Manager can make the competitors, and even the courses, from the cards as they're read.

  • [ ] Decide which computer will run the event on the day. If you're setting it up on a different one, plan to move it (see Days before).

Courses, classes and controls

  • [ ] Import the courses from Purple Pen, OCAD or Condes, or create them by hand. See Importing event data.
  • [ ] Give every class its course or courses. See Assigning courses to classes.
  • [ ] Set the Start, Finish and Check codes your units use (Event details → Radio controls). See Start, Finish and Check codes. A course with no start or finish unit of its own can start or finish at a numbered control instead; see Starting or finishing at a numbered control.
  • [ ] If you're using radio controls, mark them and set their priority per class. See Marking radio controls.
  • [ ] Upload and calibrate the event map, and — for a meshO Prime network — plan where the radios go and check every one has a path back to the Prime. See The event map and radio placement.

Entries

  • [ ] Import the entries (Eventor, IOF XML, OJSON or a CSV). See Importing event data.
  • [ ] Check every competitor has a class and a card number: sort the Competitors page by card to find the blanks. See What to check after import.
  • [ ] Refresh the Competitor registry and Club registry from Eventor, so names, clubs and cards fill in at the desk.
  • [ ] For a seeded draw, import the rankings. See Importing rankings.
  • [ ] Allocate bib numbers if you use them. See Bib numbers.

Days before ​

Start times

  • [ ] For a punching start, decide whether a punch overrides an allocated start (Event details → Starts). If another event runs the same day with the same Start and Check units, give each a Start window — see Running two events at once.
  • [ ] Draw the start times, leaving gaps for late entries if you take them (Reserve a gap every N starters). See Drawing start times.
  • [ ] Clear the start-conflict summary on the Starts screen.
  • [ ] Publish the start list: upload it to Eventor, export it, or print it. See Uploading the start list to Eventor.

Results and publishing

  • [ ] If elite classes' results are to be held back, set up results quarantine — and set a PIN (below), or the quarantine can't tell your officials' screens from the public's.
  • [ ] To publish live to liveresultat.orientering.se, create or link the competition on Event details → Live results, and decide whether it is made public when the event starts. See Publishing to liveresultat.
  • [ ] To publish the finished event to the meshO cloud, check Settings → Cloud sync and the event's Cloud sync tab. See Publishing to the meshO cloud.
  • [ ] If another results system reads Manager's files, turn on the Live export on Event details → Backup & export. See Live export.
  • [ ] Set up the spectator screens you'll use. See Creating screens.
  • [ ] Decide which info displays you'll put up — the start clock, the starters list, a radio control's feed, pending downloads — and on which devices. See Event info screens.

Printing and hire

  • [ ] Add your printers in Settings → Printing, and choose where each computer's splits and labels print. Print a test slip. See Printing splits and Where each computer's splits and labels print.
  • [ ] If you print result labels for a results board, switch them on and choose the label printer. See Result labels.
  • [ ] Put your hire cards in Settings → Hire card registry, and other lent items in Settings → Other hire registry. See Hire items.

Backups

  • [ ] Turn on auto backup for the event, and an external drive backup onto a USB stick. See Backup & export and Backup and restore.
  • [ ] For a big event, bring a second computer as a live standby, pair it in Settings → Live standby, and check it reaches In sync. See Live standby.

The computer running the event

  • [ ] If the event was set up on a different computer, move it now and work through Moving an event to another computer. Remove "(restored)" from its name if it has one.
  • [ ] Update meshO Manager on it before the day rather than on it. See Updating.
  • [ ] Set a PIN in Settings → Access protection if the event's network is shared with the public. See Access protection.
  • [ ] If any computer other than the server will read cards, back up stations or drive its own USB printer, turn on HTTPS in Settings → Server and trust the certificate on each of those computers. See HTTPS and certificates.
  • [ ] Plug in meshO Prime and check it's found on the meshO devices page (the meshO Radios icon on the Events list), and that the controls report. See Connecting meshO Prime and radios.
  • [ ] Program the SportIdent units: each control's code and mode, its switch-off time long enough for the whole day, and its clock set. See Station configuration.
  • [ ] Plan the network at the venue: how the download laptops, entry desk, TVs and phones will reach the server computer. See Multi-operator setup.
  • [ ] If it's your first event with Manager, run through the first-event walkthrough with a test event.

Morning of the event ​

Before anyone arrives

  • [ ] Start the server computer and check Manager is running (the meshO icon in the tray or menu bar).
  • [ ] Connect meshO Prime, and check it is switched on for the event (Event details → Radio controls → meshO Prime).
  • [ ] Plug the external backup drive in.
  • [ ] If you have a live standby, start it following the event, and check the Standby in sync chip on the main computer.

Every other device

  • [ ] Open Manager on each laptop and tablet from the Access links in Settings → Server (each has a QR code for phones and tablets): the IP link on download and entry-desk laptops, and the HTTPS one on any that read cards or print over USB. See Reaching the server.
  • [ ] Name each computer when it asks, such as "Download A" or "Entry desk", so the audit trail can tell them apart and its prints go where you routed them. See Naming a computer.
  • [ ] At each download desk, connect the card reader and read a test card. See Card download.
  • [ ] Print a test slip from each printer.
  • [ ] Open the registration desk and check a card on its reader finds the right person. See The registration desk.
  • [ ] Put the TV screens and info displays up, and check each shows this event.

Going live

  • [ ] Check liveresultat shows the competition, if you publish there.

  • [ ] Click Setup at the top right of the event's pages, then Start event. If Manager lists Event validation warnings, read them and fix what matters before you start. See Starting and finishing.

  • [ ] On the dashboard, check the Radio controls card shows every radio control reporting.
