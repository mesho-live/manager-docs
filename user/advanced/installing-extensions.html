Installing extensions ​

Audience: Event organisers who want to add something Manager doesn't do out of the box, usually a dashboard tile.

An extension is a small add-on someone has written for Manager, installed from a .zip file. This page covers installing, updating and removing one.

What an extension is ​

An extension adds a feature without changing Manager itself. Most add a dashboard tile: a count, a list, or something fetched from elsewhere, such as entries arriving in a spreadsheet on the day. A tile can open a competitor's Edit competitor dialog when you click something in it.

Extensions are not the same as Manager's built-in features, such as the leaderboard and commentary. Those come with Manager and are always there. An extension is something you choose to add, from whoever wrote it.

There's no extension store. You get an extension from whoever wrote it: your club, another organiser, or someone you've asked to build one.

Warning: An extension is a program. It runs in the browser of everyone who opens the event's dashboard, can read the event's data, and can make requests to websites on the internet (but not to computers on your own network). Install extensions only from people you trust.

The Extensions page ​

Open it from the Extensions icon at the top of the Events list (hover over the icons to find it). It lists every installed extension with its name, description, version and what it adds (such as Dashboard tile). It's empty until you install one.

Extensions belong to this computer, not to an event. Each event chooses which of them it uses (see Using an extension in an event).

Installing one ​

  1. Get the extension's .zip file.
  2. On the Extensions page, click Upload extension and choose the file.
  3. Manager checks the package and installs it: Extension "name" installed successfully. If the file isn't a valid extension, it says why.
  4. Switch the extension on for each event that should use it, in Event details → Extensions. See Configuring extensions.

Updating one ​

Upload the newer .zip the same way. An extension with the same name replaces the one installed, and keeps its settings. Reload any open dashboards to pick up the new version.

Removing one ​

Click the extension's remove button on the Extensions page and confirm. It's removed from this computer, and its tiles disappear from every event's dashboard. This can't be undone, but you can install it again from its .zip.

On another computer ​

Extensions are installed per computer and don't travel with an event's backup. If you move an event to another computer, install its extensions there too; the event remembers which ones it uses and their per-event settings. See Moving an event to another computer.
