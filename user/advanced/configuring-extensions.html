Configuring extensions ​

Audience: Event organisers setting up an installed extension for their events.

An extension can have settings at two levels: settings for this computer, shared by every event, and settings for one event. This page covers both, and switching an extension on for an event.

Using an extension in an event ​

An installed extension does nothing in an event until the event switches it on:

  1. Open the event and click Event details.
  2. Go to the Extensions tab. Every installed extension is listed with a switch.
  3. Switch on the ones this event should use. An extension with per-event settings shows them as soon as it's on.
  4. Click Save.

Its tile then appears on the event's dashboard. Like any tile, you can hide it or move it with Edit dashboard. See The event dashboard.

Some tiles only work while the event is running, for example one that fetches entries from elsewhere on the day. Before the event starts and after it finishes, such a tile shows a placeholder and fetches nothing.

The two levels of settings ​

LevelWhereApplies toTypical use
This computerThe Extensions page: the extension's settings buttonEvery event on this computerAn account, a key, an address the extension connects to
This eventEvent details → Extensions, under the extension's switchThis event onlyWhich spreadsheet, which classes, a colour for this event

Which settings an extension has, at either level, is up to whoever wrote it. Each is a switch, a text box, a number or a choice of colour, with the extension's own label.

Settings for this computer ​

On the Extensions page, open the extension's settings, change them, and click Save (Settings saved). They apply to every event straight away; reload an open dashboard to be sure a tile has picked them up.

Settings for an event ​

In Event details → Extensions, change the fields under the extension's switch, then Save the event details. They're saved with the event, so they go with it in a backup and when it's moved to another computer, unlike the settings for this computer.

Copying settings to another event ​

There's no copy button. A duplicated event keeps its extensions switched on with the same settings; otherwise, switch the extension on in the new event and fill its settings in again.

Getting back to the defaults ​

There's no reset button, and settings are kept on purpose:

  • An event's settings start from the extension's own defaults the first time you switch it on. Switching it off and on again keeps what you had set.
  • Settings for this computer are kept when you remove the extension, so installing it again, or a newer version, brings them back.

To go back to the defaults, set each field back by hand.
