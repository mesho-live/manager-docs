Walkthrough: your first event ​

Audience: New users — an organiser or timing operator trying Manager for the first time.

An end-to-end tour: create a small event, add some data, download a card, and view results. Everything a real event needs, but small enough to do in an afternoon at home. Each step links to a deeper page if you want the full details, and the screenshots show what you should see at each step.

Before you start ​

You'll need:

  • Manager installed and running on one computer (the "server"). See Installing meshO Manager if you haven't done this yet.
  • A web browser on the same computer, or on any other device on the same network. Chrome, Edge or Firefox 151+ is required if you want to download cards or read a SportIdent station's memory — both rely on Web Serial, which Safari and older Firefox don't support. For everything else, any modern browser works.
  • Optionally, a SportIdent USB reader station (BSM7-USB or BSM8-USB) and one or two cards, if you want to test card download. You can skip the download steps if you don't have the hardware — everything else works without it. Plug the reader into the server computer for this walkthrough: a reader on another laptop also needs HTTPS set up first (see HTTPS and certificates). On a Mac, install SportIdent's USB driver first — see SportIdent USB stations on macOS.

Tip: You don't need meshO Prime, radio controls, or a course in the forest to complete this walkthrough. Those are covered in Connecting meshO Prime and radios.

The modes of an event ​

Every event in Manager moves through three modes:

  1. Setup — the event is being built. You configure classes, courses, controls, competitors, and start times. The state button reads Setup.
  2. Live — the event is running. Card downloads work, radio punches flow in, and results are calculated in real time. The event date becomes locked; everything else — competitors, classes, start times, course assignments — remains editable, so late entries and on-the-day corrections still work. The state button reads Live.
  3. Archive — the event is finished. You can still view and export everything, and Restart event takes it live again if a late card turns up. The state button reads Complete.

You move between them with the state button at the right of the app bar at the top of the screen. It shows the event's current state, coloured to match, and clicking it opens a menu with the next step: Start event to begin, Finish event to complete, and Events to go back to the event list.

Two other states are exceptions rather than modes: Interrupted — the event was live when Manager stopped, and is waiting for you to choose Resume event — and Abandoned, an interrupted event you chose not to resume. Either can be resumed or marked finished later. See The event dashboard.

1. Open Manager ​

Open your browser and navigate to the Manager URL. If you're on the server PC itself, this is usually http://localhost:5154/manager (the default — the port can be changed in Settings → Server).

The welcome tour ​

The first time Manager is opened, a short Welcome tour runs first. It is ten steps, each with Next, Back and Skip, and a row of dots you can click to jump to a step:

  • Welcome — choose your language. It becomes the installation's default language.
  • Light or dark, your choice — the theme, saved for this computer only.
  • From small events to major carnivals and Install once, connect from anywhere — how Manager is used, from one laptop to a whole arena.
  • meshO Radios — switch on Use meshO Prime for radio punches if you have meshO radios.
  • Eventor — switch on Use Eventor and enter the Host name and API key if your federation uses it.
  • Spectator, Kiosk & Leaderboard screens — the displays for the public.
  • Ask for help — how much the built-in assistant may answer.
  • Protect Manager with a PIN — Require a PIN to open Manager, if this computer is on a network the public can reach.
  • You're ready to go! Enjoy! — finish with Get started.

Skip (or the cross in the corner) closes it; a skipped tour comes back the next time Manager is opened, until you finish it. You can replay it any time with the Welcome tour button in the top bar of the Events page.

The Events page ​

You'll land on the Events page. On a fresh install it says Welcome to meshO Manager, with a New event button, Restore from backup, Try a sample event (when the installation ships example events) and Live standby:

Underneath, Before you create your first event suggests a visit to Settings first — the gear icon at the top right — for anything you want applied to every new event. See Settings.

Note: On any computer other than the server, Manager also asks you to Name this computer the first time — a name like "Download lane A" makes the audit trail easier to read. Type one and Save, or choose Not now. The server's own browser (opened at localhost) isn't asked.

Once you have events, the page looks like this:

If Manager stopped while an event was live, the Events page asks Resume event? as soon as it opens. Resume event takes it live again; Not now leaves it Interrupted. See The event dashboard.

A shortcut: add a sample event ​

If you'd rather look at a finished event than build one, click Try a sample event (or Samples, once you have events of your own) and then Add beside the one you want. A sample you've already added says Already in your events; Add opens your copy.

Manager ships with complete example events — real classes, courses, competitors, card downloads and results. Adding one puts a copy in your event list, dated today, exactly as though you had run it yourself: browse the results and splits, print splits, put a screen up, or use Replay to watch the event unfold as if it were happening now (see The event dashboard). Change it or delete it whenever you like — it's an ordinary event and affects nothing else.

Adding a sample is the fastest way to see what a finished event looks like. Come back here afterwards to build one of your own. Everything else on the Events page — the event cards, their actions, the History tab — is described in Creating an event.

2. Create an event ​

Click New event (and, if you have Eventor switched on, Create manually… from the menu it opens).

The New event dialog asks for the Event name and Event date, both already filled in — the name after the day of the week the date falls on (e.g. "Thursday event"), the date with today — and what you're creating, as three cards: Individual, Relay or Multi-stage event.

Type something more recognisable like "Test Event" over the name, leave the date as today and the Individual card selected, then click Create. Manager creates the event in Setup with the defaults from Settings → Event defaults and takes you straight to its Dashboard. (A relay also asks for the number of legs; a multi-stage event groups several events into one.)

If you want to change the name or date later, you can:

  1. On the dashboard, click Event details at the top left.
  2. Change Event name (and Event date, if you want a future date) on the Details tab.
  3. Click Save.

Shortcut — import from Eventor: If your organisation uses Eventor and you've already configured the connection in Settings → Eventor, you can choose Import from Eventor… from that same button instead. Manager will fetch a list of events, let you pick one, and import classes, competitors, clubs, and start times in one step. If you go this route, you can skip ahead to step 6 (the dashboard). See Creating an event from Eventor for the full details.

3. Create a course ​

Before you start the event, you need at least one course. For this test, you'll make a short one.

  1. In the event menu on the left, click Course (at the top, beside Entries and Race), then Courses.
  2. Click Actions → Add…. The Add course dialog opens.
  3. On the Details tab, give the course a Course name — for example "Short". Leave Course format as it is (a line course, visited in order, unless the event is set up for scatter courses).
  4. Open the Controls tab. Type each control code and press Enter after each one. For example, type 31, Enter, 32, Enter, 33, Enter. The controls appear as chips that you can drag to reorder.
  5. Click Save.

You now have a 3-control course. The controls are created automatically as you add them.

Tip: In a real event, you'd typically import courses from a Purple Pen file or IOF XML rather than typing them by hand. See Classes and courses.

4. Create a class and assign the course ​

A class is a category of competitors (e.g. M21E, W18A). A class typically runs a single course — although more than one can be assigned if you need it.

  1. In the event menu, click Entries, then Classes.
  2. Click Actions → Add….
  3. Enter a Class name — for example "Open".
  4. In the Courses field, select the "Short" course you just created.
  5. Click Save.

Tip: For a quick event where each course is its own class, turn on Create class in the Add course dialog, or use Auto create classes from courses… from either page's Actions menu. See Classes and courses.

5. Add a few competitors ​

  1. In the event menu, under Entries, click Competitors.
  2. Click Actions → Add….
  3. Fill in First name and Surname, and choose the "Open" class under Class.
  4. If you have a card, enter its number in the Card number field. Otherwise leave it blank for now.
  5. Click Save, and repeat for one or two more competitors. (Turn on Keep adding to keep the dialog open for the next one.)

You should now see your competitors listed with their class, and a status of None (no result yet).

Tip: In a real event, competitors and their card numbers come from the entry system (Eventor, IOF XML import, or on-the-day registration). Typing them by hand is only needed for small events or late entries. See Competitors, clubs and teams.

6. Explore the dashboard ​

Click Dashboard at the top of the event menu.

The dashboard is your central view during an event. Along its top are Event details (the event's settings, from name and date to printing and backups) and Edit dashboard, which lets you move, resize and hide the tiles below. Then you'll see several tiles:

  • Event data — how many controls, courses, classes, competitors, teams and clubs the event holds, with an Import button.
  • Competitors — counts by status: Total, Not started, Started, On course, Pending and Finished, with a chart of how many are on course over time. In a brand-new event everyone is Not started.
  • Quick actions — a quick-search panel where you can look up any competitor, change their card number, reassign them to a different class on the fly, or print their splits. You can also add a new competitor from here.
  • Download card — the card reader's status and the latest download. Until the event is live it says Card download is available while the event is running.
  • Spectators — once the event is live, how many people are following the event on the spectator site and kiosk.

Other tiles appear depending on your event configuration:

  • Radio controls — when the event uses meshO Prime radios.
  • Radio punch forwarding / SIRAP punch listening — when the event forwards or accepts punches over the network.
  • Liveresultat — when the event publishes to liveresultat.orientering.se.
  • Recent downloads and Pending downloads — off to begin with; add them with Edit dashboard.
  • Extension tiles — any tiles contributed by installed extensions.

Don't worry about the conditional tiles for this test. For the full tour of every dashboard card, see The event dashboard.

Finding your way around an event ​

Every event page has the same frame around it.

The app bar across the top shows the event's name, its date and facts (type, level, discipline, start type), and on the right:

  • Ask (the robot face) — the built-in assistant, when it is switched on.
  • The event clock — the running event time while the event is live.
  • The state button — Setup, Live, Complete and so on, with the menu that starts and finishes the event.

The event menu down the left starts with Dashboard, then a switch between three modes, each with its own screens:

ModeScreens
CourseCourses, Controls, Legs, Map
EntriesCompetitors, Classes, Clubs, Relay teams (relay events), Starts, Hire items
RaceCard downloads, Radio punches, Radios, Live view, Tracking, Results, Leaderboard, and under Admin: SportIdent station, Screens, Spectators, Audit trail

An event in Setup opens on Entries; a live or finished one on Race. The numbers beside a screen are how many items it holds. Screens about radios and Prime appear only when the event uses them, and screens such as Card downloads open before the start too, saying what fills them in once the event is live.

At the foot of the menu, Go to… (or Ctrl+K, ⌘K on a Mac) finds any screen, Event settings itself and any of its tabs, by typing part of its name. It also opens what the dashboard does, from any page: Add competitor, Import (courses, classes, entries and start times), the On course, Not started and Pending (competitors not downloaded) lists, Events, which closes the event and goes back to the events list (type close to find it), and Ask the assistant where the assistant is switched on. Whichever of Start event, Resume event, Finish event and Mark finished the event's state menu offers right now is listed too, and asks for the same confirmation. The list opens as soon as the search does: the up and down arrows move through it, and Enter opens the highlighted entry. Typing settings lists every tab of Event settings, and map finds the Live view as well as the Map. With the menu folded, Ctrl+K opens the search in the middle of the page and leaves the menu folded.

The ≡ button beside Dashboard folds the menu to a column of icons; each mode's screens then open beside it. A window narrower than 1024 pixels starts folded.

The alerts panel ​

The narrow strip on the right of every event page is the Alerts panel, folded away. Click the arrow at its top to open it. Alerts lists the serious problems that need someone to act — a radio's battery critically low, a lost connection — and Messages below keeps a running log of everything reported, including alerts already dealt with. The panel opens by itself when a new alert arrives, and the strip shows meshO Prime's connection state at its foot.

The cross on an alert dismisses it: it leaves the Alerts list but stays under Messages, and a fresh alert appears if the problem changes again. See Connecting meshO Prime and radios for the radio alerts you'll meet most.

Language and theme ​

The flag at the top right of the Events page (and of the registration desk, info displays, spectator site and kiosk) opens a menu of languages, with three theme buttons underneath: follow the device, light and dark. Both choices are saved for this computer only, so every operator can have their own. See Settings → This computer for the rest of this computer's display settings.

7. Start the event ​

Downloads, radio punches, and live results only happen once the event is in progress. Right now your event is still in Setup.

Click the Setup button at the right of the app bar. (On arriving at an event in Setup, this menu opens by itself for a few seconds.) It says Event is not live and offers Start event, with Events underneath to go back to the event list. (Replay also appears on an event with a recorded day to play back, such as a sample.)

Click Start event. Manager checks your event for problems first — no courses, no classes, no competitors, classes with no course assigned, competitors due to leave the start together — and if everything looks good, takes the event Live. The state button turns green and reads Live, the event clock starts, and the menu now offers Finish event (for later). Starting and finishing on the dashboard page covers every state and what each one offers.

Tip: If Manager finds a problem, an Event validation warnings dialog lists what it found and asks whether to start anyway. Click Continue to start regardless, or Cancel, fix the issue, and click Start event again.

Note: An event dated in the future asks whether to Start in test mode instead, so keep this test event's date as today. An event whose date has passed without ever being run can't be started until you change its date. A second event can be live at the same time; see Running two events at once.

8. Download a card ​

Skip this step if you don't have a SportIdent USB reader and a card.

Browser requirement: this step needs Chrome, Edge or Firefox 151+ — the SI reader uses the Web Serial API, which Safari and older Firefox don't support.

This is the core during-event action: a competitor finishes, hands in their card, and you read it.

  1. In the event menu, under Race, click Card downloads.
  2. The SportIdent panel says Connect a SportIdent reader to download cards. with a Select device button.
  3. Plug your SI reader into a USB port, then click Select device. Your browser will show a system dialog listing available serial devices — pick the SportIdent reader and confirm.
  4. The status changes to Listening. The page now says Insert SportIdent card.

Now insert the card in the reader:

  • A progress bar appears while the card is read.
  • If the card number matches a competitor you entered in step 5, you'll see a green OK banner with the competitor's name, class, place and time.
  • If the card number doesn't match anyone, you'll see an orange Unassigned banner. Manager gives you the option to assign it to an existing competitor or create a new one right there.
  • If the card is missing a required punch, you'll see a Missing Punch (MP) result. You can change the competitor's class to one where the punches are valid, or later approve the missed control on their Overrides tab (see Resolving issues on the day).

The right side of the page is the Downloads table with every card you've read — searchable, with a Filter button. Underneath the reader panel, the splits printer and result-label printer this computer prints to are shown, with Change.

For the full details on every download scenario, see Downloading cards.

9. See radio punches (optional) ​

If you have meshO Prime connected with radio controls in the field, the Radio punches page (under Race) shows punches arriving in real time — a table of card number, competitor name, control and punch time, with the most recent at the top.

For this at-home test you probably don't have a radio network, so feel free to skip this. See Radio punches and Connecting meshO Prime and radios when you're ready for the real thing.

10. Watch the leaderboard ​

During an event, the Leaderboard is how everyone follows things as they unfold. It updates live: every radio punch, every card download, every status change appears the moment it happens. No refreshing, no re-running a report.

While the event is live, open Leaderboard under Race in the event menu to see it inside Manager (see Leaderboard). For a TV, open Screens (under Race → Admin) and click the name of the built-in all screen. It opens in a new browser tab, showing every class: the current finishers, who's still out, and how the order changes as new results come in. This is the view you'd put on a TV at the arena, or keep open on a second screen while you work.

The Screens page lists every screen that has been opened, what it shows and which classes, with New to set up more and Leaderboard classes beside it:

For more on screens and their configuration, see Creating screens and TV screens.

11. View the results ​

The Results page is the operator's view of the same data — detailed, filterable, built for checking and exporting rather than live display.

Open Results under Race in the event menu. You'll see results grouped by class.

For each class, competitors are listed in finishing order with their time. Competitors with a problem status like MP or DNF appear below the finishers.

Use the panel on the right to:

  • Group by class or course, and pick Classes / Courses or an Organisation to narrow the list.
  • Show behind time to see the gap to the leader, and Show summary for the counts at the top of each class.
  • Include competitors who are normally left out: Provisional results, On course competitors, Status none competitors and Did not start. These change what you see on screen only — an exported results file always accounts for everyone who took part, whatever is ticked here. See What an exported results file contains.

When you're ready to share results, open Publish at the top of the page:

  • Upload to Eventor… sends results straight to Eventor from within Manager (offered when Eventor is set up).
  • Export IOF XML… downloads a results file for other systems (or to upload to Eventor by hand). Export JSON… and Export PDF… are beside it.
  • Print view… gives you a printable version, and Print to splits printer… prints the results on the splits printer.

When you've finished, click the Live button in the app bar and choose Finish event to move the event to Archive.

If competitors still have no settled result, Manager lists them first under Event not finalised, with buttons to settle them, or Finish anyway:

For the full details, see Results.

12. What's next ​

You've just walked through the core loop of meshO Manager — create an event, define its structure, register competitors, download cards, and view results. A real event adds more layers:

  • Importing data from Eventor, IOF XML, or Purple Pen so you don't type everything by hand. See Importing event data.
  • Connecting meshO Prime to get live radio punches from controls in the forest. See Connecting meshO Prime and radios.
  • Setting up spectator screens on TVs at the arena. See Creating screens and TV screens.
  • Letting competitors follow on their phones, and a kiosk at the finish. See The spectator site and kiosk.
  • Running commentary for the announcer. See Commentary.
  • Handling problems — missing punches, unknown cards, overdue competitors. See Resolving issues on the day.
  • Multiple operators working simultaneously on different laptops. See Multi-operator setup — remember, Manager is multi-user by default. Other volunteers just open the same URL in their browser.
  • An entry desk for on-the-day entries and hire cards. See The registration desk and Hire items.
  • Accounting for everyone at the end of the day. See Safety check.

Before your first real competition, work through the Pre-event checklist to make sure nothing is forgotten.
