Which address each workstation uses ​

The one part of this page that's written, because it catches people out every time.

Settings → Server offers each app under two kinds of address — the computer's name and its LAN IP. Which one a workstation should use depends on what that workstation is:

  • Admin laptops — card download, station backup, the entry desk — should use the IP links. These machines need a browser with Web Serial (Chrome, Edge or Firefox 151+) to read a SportIdent reader, and in practice that means Chrome, which frequently can't resolve the computer's name.
  • Phones, tablets and spectator TVs should use the name links. Mobile operating systems resolve the name automatically, and a name survives the server's IP changing.

If you'd rather give every machine a name, add a DHCP reservation with a host name on the venue router — that name is served by ordinary DNS, so every browser resolves it.

Full detail, including the exact Chrome error and how to set the router up: Reaching the server: name or IP.
